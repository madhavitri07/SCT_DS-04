Traffic Accident Data Analysis & Hotspot Visualization
 Project Overview

This project focuses on analyzing traffic accident data to identify patterns related to road conditions, weather factors, and time of day. The goal is to uncover insights that can help understand accident severity and highlight accident-prone areas using data analysis and visualization techniques.

The project was completed as Task 3 of my Data Analytics Internship.

 Dataset

Source: US Accidents Dataset (GitHub Repository Version)

Records Used: ~100,000 accident records

Features:

Accident severity

Geographical coordinates (latitude & longitude)

Weather conditions

Road infrastructure indicators (signals, junctions, crossings, etc.)

Time-based attributes (day/night, twilight phases)

 Due to dataset download limitations from Kaggle, the dataset was accessed via the official GitHub repository for successful analysis and submission.

 Tools & Technologies Used

Python

Pandas & NumPy – Data cleaning and manipulation

Matplotlib & Seaborn – Exploratory Data Analysis (EDA)

Folium – Interactive accident hotspot mapping

Jupyter Notebook

 Exploratory Data Analysis (EDA)

Analyzed accident severity distribution

Examined weather conditions during accidents

Studied accidents by time of day (Day/Night & Twilight phases)

Identified relationships between road features and accident severity

 Accident Hotspot Visualization

Used Folium to plot accident locations on an interactive map

Highlighted high-density accident regions

Enabled geographical analysis of accident-prone zones

 Key Insights

Majority of accidents occurred during daytime hours

Higher accident concentration observed near traffic signals and junctions

Weather conditions such as low visibility and precipitation showed increased accident impact

Urban areas recorded a higher frequency of traffic incidents
